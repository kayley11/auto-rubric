# Linked scoring evidence

Open a saved score in **Case review**, or select **View linked evidence & add a note** in a saved evaluation.

- **Evidence:** locates explicit judge quotations in the saved answer. Unique literal matches appear as Recogito highlights. Automatic links remain **awaiting review**. Rewritten, elided or ambiguous quotations receive an explanation instead of a forced match.
- **Rubric:** shows the saved definition, all grading levels and the rule version used for that assessment. The saved grade is marked.
- **Case:** shows supplied facts, the original task and saved questions and replies. Scoring references are labelled separately.

Select answer text to create a highlight. Enter a reviewer ID, add a note and save it to the protected workspace. Reopening the same answer and item restores the note. Each revision is saved separately and is bound to fingerprints of the answer, reason and rubric. Checking a link leaves the saved score unchanged.

Clinical references and candidate requirements remain **awaiting confirmation**. The original answers, grades, explanations and complete plain-text/JSON outputs remain available. Blind review retains its existing score-reveal rules.
