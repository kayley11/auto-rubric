# 网站离线、文本格式和高亮确认排查记录

日期：2026-11-17。没有生成新临床回答，也没有重新评分。

## 1. 为什么电脑开着，网站仍显示 offline

网页、网站后端、公开隧道和 KCL 模型接口是不同的连接。连上 CREATE，不等于网站的登录与评估后端可以从公网访问。

这次观察到两处实际故障：

| 检查位置 | 修复前的证据 | 对网站的影响 |
|---|---|---|
| 本机 Python 后端 | 进程还在，但已有 6,144 个线程；日志累计 10,335 次 `can't start new thread`。本地健康请求被重置。 | 新登录和 API 请求无法正常处理。 |
| 后端线程栈 | 大量请求等待 Python 锁，SQLite 打开／关闭连接的线程在原生互斥锁中等待。本地十线程数据库读取测试也复现了打开／关闭阻塞。 | 后续请求不断积累，最终耗尽请求线程。 |
| 临时 Cloudflare 隧道 | 进程还在，但重复返回 `Unauthorized: Tunnel not found`。 | 网站找不到有效的后端通道。 |
| 原恢复程序 | 主要判断子进程有没有退出；未恢复“进程活着但无响应”和“隧道分配已失效”。 | 恢复进程仍运行，却一直无法恢复连接。 |

代码中还确认了一处连接管理问题：`with sqlite3.connect(...)` 只结束事务，并不会自动关闭数据库连接。不能把全部故障只归因于这一点；这次还实际复现了并发打开／关闭时的 SQLite 阻塞。

已做的修复：

- 会员、任务队列、批次、人工复核和个人 API 连接五处存储统一明确关闭数据库连接。
- 将短数据库事务及打开／关闭放在同一把锁内。模型调用在这把锁之外，原有模型任务队列保留。
- HTTP 请求线程最多 64 个；满载返回可重试的 503，不再无限开线程；连接有空闲超时。
- 后端连续三次不响应时，恢复程序只重启自己启动的后端，不停止其他占用端口的程序。
- 发现 `Tunnel not found` 时重新建立临时隧道，并自动更新公开网址的连接登记。
- 登录页不再将无法连接直接说成“电脑没开机”；提供 Check connection。

确认当时没有运行或排队中的模型任务后，重启了这组已核实的后端和隧道进程。没有重建账号、密码或结果目录。

## 2. 查了哪些文本，修复了哪些格式

扫描了全部 506 个公开 JSON 文件中的 458,456 个字符串字段，包含当前 135 个病例、模型回答、逐项评分理由、引文、rubric 和保留的历史数据。另对本机 455 个私有记录 JSON 做了只读检查；私有文本没有写入公开验证文件。

| 发现 | 处理 |
|---|---|
| 当前主结果中 17 份回答使用了 LaTeX 写法，例如 `311 $\mu$mol/L`。相关引文也保留这些符号。 | 阅读时显示为 `311 μmol/L`；箭头、β、≥、≈和数字上下标也通过同一阅读层处理。 |
| rubric 的一处说明公式在保存的显示文本中丢了乘号，并在不同病例中重复出现。 | 回查归档 `main.tex` 第 336 行，确认原文为 `1$\times$minor` 和 `3$\times$major`，仅对这个完全匹配的片段恢复显示。没有猜测其他公式的运算符。 |
| 一些截断引文带着单侧 `**`，另一些历史复核问题以多余的 `** ` 开头。 | 阅读层隐藏这些格式残留；不补写被截掉的临床文字，不把截断或改写引文强行认作准确原文。 |
| 历史问诊记录中有 41 个技术正则字段，例如 `\b...\b`。 | 它们是原始匹配规则，不是公式；保留在原始记录中。 |

658 个带数学格式的字段通过阅读层显示，包含相同材料在不同档案中的重复副本，不能解读为 658 个独立错误。修复后的扫描中，临床文字没有残留已检查的 LaTeX 命令或 Markdown 标题／双星号格式；技术正则字段单独排除。

17 个受影响的当前病例：BN01、BN02、BN04、BN05、BN09、BN14、BN18、BN19、BN20、BN23、BN31、BN37、BN44、BN46、BN48、BN56、BN57。

所有修复都在阅读层完成。原始回答、原始评分理由、原始导出和用于保存批注的原文 UTF-16 位置不改。阅读层对每个显示字符保留原文位置，因此旧批注和蓝色引文仍可定位。Plain-text output 和 Saved data (JSON) 是原始内容查看入口，仍保留原始格式。

## 3. 选中文字不再自动变成绿标

旧行为来自 Recogito 默认的创建模式：选中文字会立即创建一个手动标记。它不等于已经提交评分，但界面容易让人误解。

现在的步骤是：

1. 选中文字：显示 Highlight this passage?，绿色标记数不变，不保存记录。
2. 点 Cancel、按 Escape、点击其他位置或滚动：关闭提示，不创建绿标。
3. 点 Highlight：才创建当前视图中的绿色草稿，并说明 No rating has been submitted。
4. 要永久保存，在右侧填写说明并点 Save evidence note。这个动作只保存证据批注，不改变病例分数或临床参考状态。

原有已保存批注保留。蓝色仍代表当前条目的自动引文匹配，自动关联仍 awaiting review；绿色只代表用户确认创建的高亮，不代表内容正确或人工评分已完成。
